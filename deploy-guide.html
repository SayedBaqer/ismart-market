Four free accounts, five steps, and every future code change deploys automatically in under a minute.

Phase 1
Push your code to GitHub
1
Create a GitHub repository

Go to github.com/new and create a new repo.
Name it ismart-market · Set to Private · Do NOT add README · Click Create repository.

If you don't have a GitHub account yet, sign up free at github.com.

2
Connect your local code to GitHub

In your terminal, inside the project folder, run these two commands:

Terminal
$ git remote add origin https://github.com/YOUR_USERNAME/ismart-market.git $ git push -u origin master

Replace YOUR_USERNAME with your actual GitHub username. Your code is now on GitHub.

Phase 2
Set up your free database (Neon)
1
Create a Neon account

Go to neon.tech and sign up with GitHub (fastest). No credit card needed. The free tier gives you 500 MB and is free forever.

2
Create a project

Click New Project · Name it ismart · Choose the region closest to Bahrain (usually EU West) · Click Create Project.

3
Copy your DATABASE_URL

On the dashboard you'll see a connection string. Click "Connection string" and copy it — it looks like this:

Example
postgresql://username:password@ep-xxx-yyy.eu-west-2.aws.neon.tech/neondb?sslmode=require

Save this somewhere — you'll paste it into Vercel in Phase 4.

Phase 3
Set up image storage (Cloudinary)
1
Create a Cloudinary account

Go to cloudinary.com and sign up free. Free plan includes 25 GB storage and 25 GB bandwidth per month — more than enough.

2
Copy your API environment variable

After login, you land on the Dashboard. Look for the box labelled "API environment variable" — it's in the middle of the page. Click copy. It looks like:

Example
cloudinary://123456789012345:abcDEFghiJKL@your-cloud-name

This single string has everything the app needs to upload images. Save it alongside your DATABASE_URL.

Phase 4
Deploy to Vercel
1
Create a Vercel account

Go to vercel.com and sign up with GitHub. This lets Vercel read your repos and auto-deploy on every push.

2
Import your project

Click "Add New Project" → find ismart-market in the list → click Import.

Do not click Deploy yet. You need to set environment variables first.

3
Add environment variables

Scroll down to the "Environment Variables" section. Add each row below:

Variable Value
DATABASE_URL Your Neon connection string required
CLOUDINARY_URL Your Cloudinary API env var required
AUTH_SECRET Any random 32+ character string required
NEXTAUTH_URL https://ismart-market.vercel.app (update after deploy)
NEXT_PUBLIC_APP_URL https://ismart-market.vercel.app (same as above)
NEXT_PUBLIC_APP_NAME iSmart Market
NEXT_PUBLIC_BASE_CURRENCY BHD

For AUTH_SECRET — open any password generator site, generate 32+ random characters, paste it in. Or run this in your terminal:

Terminal
$ node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"
4
Set the build command

Under "Build and Output Settings", override the Build Command to:

Build Command
npx prisma migrate deploy && npx prisma db seed && next build

This creates all database tables and seeds the default admin account automatically on every deploy.

5
Click Deploy

Vercel will build and deploy. It takes 2–4 minutes on the first run. When done, you'll get a URL like ismart-market.vercel.app.

💡
Update your URLs

Once deployed, copy the real URL Vercel assigned. Go to Project Settings → Environment Variables and update both NEXTAUTH_URL and NEXT_PUBLIC_APP_URL to that URL, then click Redeploy once.

6
Log in for the first time

Go to yoursite.vercel.app/admin/login

First login credentials
# Email admin@ismart.market # Password admin123456
⚠️
Change this password immediately

Go to Admin → Users → your account → change password before doing anything else.

Domain
Your site address / domain name
✖
.tk domains are no longer available

Freenom (the company that offered free .tk, .ml, .ga domains) lost a lawsuit from Meta in 2023 and has been offline for new registrations ever since. You cannot get a .tk domain right now.

Here are your real options:

✓ Free · Best choice
ismart-market.vercel.app

Your site already has this address from Vercel. It's free, HTTPS, fast, and perfectly fine for production. Most marketplace portals run on a subdomain like this. No extra setup.

~$8/year
ismartmarket.com (or .store / .shop)

Buy from Namecheap or Porkbun. Add it in Vercel: Project → Settings → Domains → Add. Vercel handles HTTPS automatically. .store domains sometimes go for $1–$3 in the first year.

Free · Slow approval
eu.org subdomain

Completely free real domain (e.g. ismart.eu.org) but approval takes 2–8 weeks and requires manual review. Apply at nic.eu.org.

Updates
How to update your live site

After the first deploy, every future update is just two commands. Vercel picks up your push and deploys in about 60–90 seconds.

✏️ Edit code Make changes in VS Code / Claude
→
📦 Commit git add & commit
→
🚀 Push git push
→
⚡ Live in ~60s Vercel auto-deploys
Every future update
# After making changes... $ git add -A $ git commit -m "describe your change" $ git push # That's it. Vercel deploys automatically.
👁
Watch your deploy

Go to vercel.com/dashboard → your project → you'll see each deployment in real time with logs. If a build fails, the old version stays live — your site never goes down from a bad push.
